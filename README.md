# Life 900 Months

多年前，我受到一个说法的启发：如果把人生看作 900 个月，并把它画在一张 30 x 30 的方格纸上，人会立刻感受到时间的有限。

后来，在我老婆的提醒下，这个想法变得更具体。她说，如果把父母的人生格子也放在同一个视图里，我们会更直观地知道生命有多么短暂，也多么残酷。于是我们真的这样做了。

我们还把生命里重要的时间点标在各自的 30 x 30 方格上：开始工作的月份、结婚的月份、孩子出生的月份，以及其他值得记住的节点。这样一来，人生不再只是一个抽象的数字，而是一张可以一眼看懂的地图。

这个项目就是这个想法的 Web 版本。

## 当前功能

- 选择出生年月后，生成 900 个月的人生方格。
- 用不同状态标记过去、当前和未来的月份。
- 添加家人或重要成员，并在同一个视图中看到他们所处的人生月份。
- 添加重要月份，例如工作、结婚、孩子出生等人生节点。
- 支持 emoji 或图片作为个性化标记。
- 数据目前保存在浏览器本地。

## 本地运行

项目当前是一个纯静态 Web 应用，不需要安装依赖。

```bash
cd /Users/harry/life_900_months
python3 -m http.server 4173
```

然后打开：

```text
http://localhost:4173
```
